## Confirmed results

- All eight host checks passed.
- NPU KV pool, SFA INT8, INT8 indexer and DCP prefix/HCCL groups passed.
- Three MoE device tests passed; fused GMM2 failed in the ND V3 operator,
  which rejected INT8 weight storage (`DT_INT32` required).
- Baseline serving qualification passed: 1349 compared logprobs, maximum
  absolute error 0, unchanged atol/rtol 0.01. This is a repeatability check
  against the same checkpoint, not quantization accuracy against BF16.
- The timed server loaded, became ready and flushed its cache successfully.
- AISBench exited before sending measured requests. The host client log
  `results/baseline/aisbench-1.log` contains
  `CondaError: Run 'conda init' before 'conda activate'`.
  `results.json` correctly records failure phase `aisbench/1`.
  No TTFT, TPOT or throughput was measured.

The later server SIGTERM/EOF messages follow runner cleanup. They are not
an inference crash in this experiment.

## Fixes

1. Initialize the installed Conda Bash hook before sourcing the host AISBench
   environment script. Resolve its executable from `CONDA_EXE` or PATH;
   preserve failures in hook generation, environment activation and client
   execution. No profile edits or dependency upgrades are needed.
2. Make `start_a3_retest.sh quick` select only `serve` qualification and the
   baseline timing case. Its NPU environment preflight still runs. Host/device
   family suites remain the default for all other modes and are not relabeled.
3. Initialize SGLang's NPU backend in the standalone fused-GMM2 device test,
   so internal format policy matches serving. Verify the resulting NZ format.
   Preserve the production W8A8 transpose/cast order and parity tolerance.
4. Require real INT8 NZ storage and a WeightNz CANN entry point before enabling
   fused GMM2. Schema presence and INT8 dtype alone do not establish compatibility.
   The direct call also rejects an incompatible weight/operator contract before
   launching the kernel. Packed W4A8 weights remain ineligible.
5. Archive the entire host experiment directory, including the client log,
   exception, settings, reports and copied server artifacts. Snapshot the driver
   log before archiving to avoid reading a file that tee is still writing.

The op-plugin [dispatch implementation](https://github.com/Ascend/op-plugin/blob/master/op_plugin/ops/opapi/GroupedMatmulFinalizeRoutingKernelNpuOpApi.cpp)
selects the WeightNz API using the storage format. This explains the observed
ND V3 call; the installed binary's precise source revision was not supplied.
The test's missing backend initialization is a concrete setup defect. Its NPU
repair still needs rerunning on the target; do not promote a CPU mock to device
parity or claim that the full W4A8 model now activates TP finalize.
